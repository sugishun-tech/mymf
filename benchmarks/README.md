# Reproducible measurements

See [../docs/benchmarks.md](../docs/benchmarks.md) for protocols, all result tables,
thread-budget caveats and memory limitations. `results/` contains unedited numeric
records from local runs, including seeds, individual timings and quality values.

No downloaded recommendation dataset is bundled. All supplied results are synthetic.
The scripts are standalone Python entry points, requiring the installed mymf package.
